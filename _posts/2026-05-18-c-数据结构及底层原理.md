###### 核心容器底层原理

1. std::vector - 动态数组

```
// 底层结构
  struct vector_impl {
      T* _M_start;         // 起始位置
      T* _M_finish;        // 当前末尾
      T* _M_end_of_storage; // 存储空间末尾
  };
  
初始: capacity=4, size=3
  [ A ][ B ][ C ][    ]
                    ↑ finish
                        ↑ end_of_storage

  push_back(D)后:
  [ A ][ B ][ C ][ D ]
                    ↑ finish
                    ↑ end_of_storage

  push_back(E)触发扩容:
  新分配capacity=8:
  [ A ][ B ][ C ][ D ][ E ][    ][    ][    ]
                                ↑ finish
                                            ↑ end_of_storage
```

关键特性：
  - 连续内存：元素在内存中连续存储，支持随机访问 O(1)
  - 扩容机制：capacity 不足时，按 2倍 扩容（GCC/Clang）或 1.5倍（MSVC）
  - 扩容成本：分配新内存 → 拷贝/移动元素 → 释放旧内存 → O(n)



2. std::deque - 双端队列

```
// 底层：分段连续内存 + 中控器
  struct deque_impl {
      T** _M_map;           // 中控器（指针数组）
      size_t _M_map_size;   // 中控器大小
      T* _M_start;          // 起始迭代器
      T* _M_finish;         // 末尾迭代器
  };

  中控器
  ┌─────┬─────┬─────┬─────┬─────┐
  │  *  │  *  │  *  │  *  │  *  │  指针数组
  └──┬──┴──┬──┴──┬──┴─────┴─────┘
     │     │     │
     ▼     ▼     ▼
  ┌─────┐ ┌─────┐ ┌─────┐
  │缓冲区│ │缓冲区│ │缓冲区│  每个缓冲区固定大小(512字节/sizeof(T))
  │[...]│ │[...]│ │[...]│
  └─────┘ └─────┘ └─────┘

  头插/尾插 O(1)，中间插入 O(n)
```

3. std::list - 双向链表

```
// 节点结构
  struct _List_node {
      _List_node* _M_prev;
      _List_node* _M_next;
      T _M_data;
  };

  // 环形链表，有一个哨兵节点
  // [sentinel] ⇄ [node1] ⇄ [node2] ⇄ [sentinel]
```



 特性：
  - 任意位置插入删除 O(1)
  - 不支持随机访问
  - 内存不连续，缓存不友好

4. std::map/set - 红黑树

```
 // 红黑树节点
  struct _Rb_tree_node {
      _Rb_tree_color _M_color;  // 红/黑
      _Rb_tree_node* _M_parent;
      _Rb_tree_node* _M_left;
      _Rb_tree_node* _M_right;
      T _M_value_field;
  };
  
          B(10)
         /     \
      R(5)     R(15)
      /   \      \
    B(3) B(8)    B(20)

  查找/插入/删除: O(log n)
```

 红黑树性质：

4.1节点是红色或黑色

4.2根节点是黑色

4.3叶子节点(NIL)是黑色

4.4红色节点的子节点必须是黑色

4.5任一节点到叶子的所有路径包含相同数量的黑色节点



5. std::unordered_map - 哈希表

```
// 底层结构
  struct unordered_map_impl {
      vector<bucket> _M_buckets;  // 桶数组
      float _M_max_load_factor;   // 负载因子阈值(默认1.0)
  };

  桶数组
  ┌───┬───┬───┬───┬───┬───┬───┬───┐
  │ 0 │ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │ 7 │  桶索引 = hash(key) % bucket_count
  └─┬─┴───┴─┬─┴───┴─┬─┴───┴───┴───┘
    │       │       │
    ▼       ▼       ▼
  [链表]   [链表]   [链表]   拉链法解决冲突

  平均: O(1)，最坏: O(n) (所有key冲突)
  
   扩容触发条件：
  load_factor = size / bucket_count;
  if (load_factor > max_load_factor) {
      rehash(bucket_count * 2);
  }
```

6. 容器适配器

```
// stack - 默认基于deque
  template<typename T, typename Container = deque<T>>
  class stack {
      Container c;
      void push(const T& x) { c.push_back(x); }
      void pop() { c.pop_back(); }
  };

  // queue - 默认基于deque
  template<typename T, typename Container = deque<T>>
  class queue {
      Container c;
      void push(const T& x) { c.push_back(x); }
      void pop() { c.pop_front(); }
  };

  // priority_queue - 默认基于vector + 堆算法
  template<typename T, typename Container = vector<T>,
           typename Compare = less<T>>
  class priority_queue {
      Container c;
      void push(const T& x) {
          c.push_back(x);
          push_heap(c.begin(), c.end());
      }
  };

```
