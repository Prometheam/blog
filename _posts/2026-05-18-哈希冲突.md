哈希冲突及其解决办法

###### 一、什么是哈希冲突

哈希函数: hash(key) → 索引位置

  理想情况: 每个key映射到唯一位置
  实际情况: 不同key可能映射到相同位置 → 冲突

  示例:
  hash("abc") = 5
  hash("xyz") = 5  ← 冲突！

  冲突不可避免的原因（鸽巢原理）：
  - 键值域无限（如所有可能的字符串）
  - 哈希表容量有限
  - 必然存在多个键映射到同一位置

###### 二、主要解决方法

---

方法1：链地址法

  原理： 每个桶存储一个链表，冲突元素追加到链表

```
桶数组
  ┌───┬───┬───┬───┬───┬───┬───┬───┐
  │ 0 │ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │ 7 │
  └─┬─┴───┴─┬─┴───┴─┬─┴───┴───┴───┘
    │       │       │
    ▼       ▼       ▼
   NULL    [A]→[D]  [B]→[E]→[C]
           hash(A)=1  hash(B)=4
           hash(D)=1  hash(E)=4, hash(C)=4
```

 优点：
  - 实现简单
  - 对装载因子不敏感
  - 删除操作简单

  缺点：
  - 链表指针消耗额外内存
  - 缓存不友好（链表节点分散）
  - 极端情况下退化为链表 O(n)

---

方法2：开放地址法

  原理： 冲突时按规则探测下一个空位

```
  插入 key=5, hash(5)=2, 但位置2已被占用
  线性探测: 尝试 2→3→4→... 直到找到空位
  ┌───┬───┬───┬───┬───┬───┬───┬───┐
  │   │   │ A │ B │   │   │   │   │
  └───┴───┴───┴───┴───┴───┴───┴───┘
                ↑
            冲突，继续探测
                ──────→ 找到位置4
```

探测策略

  1. 线性探测
    // 探测序列: h, h+1, h+2, h+3, ...
    size_t probe(size_t h, size_t i, size_t capacity) {
      return (h + i) % capacity;
    }

```
问题： 容易形成聚集
  ┌───┬───┬───┬───┬───┬───┬───┬───┐
  │ X │ X │ X │ X │ X │   │   │   │
  └───┴───┴───┴───┴───┴───┴───┴───┘
                    ↑
              主聚集区：新插入更可能落在这里
```

  2. 二次探测
    // 探测序列: h, h+1², h+2², h+3², ...
    size_t probe(size_t h, size_t i, size_t capacity) {
      return (h + i * i) % capacity;
    }

  // 或: h + i² 和 h - i² 交替
  size_t probe(size_t h, size_t i, size_t capacity) {
      int offset = ((i + 1) / 2) * ((i + 1) / 2);
      if (i % 2 == 0) offset = -offset;
      return (h + offset + capacity) % capacity;
  }

  3. 双重哈希
    // 探测序列: h1 + i * h2
    size_t probe(size_t h1, size_t h2, size_t i, size_t capacity) {
      return (h1 + i * h2) % capacity;
    }

  // 需要两个独立的哈希函数
  size_t hash1(const K& key) { return std::hash<K>{}(key); }
  size_t hash2(const K& key) { return 1 + std::hash<K>{}(key) % (capacity - 1); }

方法3：再哈希法

 ```
 // 使用多个哈希函数，直到找到空位
  size_t idx;
  for (int i = 0; i < MAX_HASH_FUNCTIONS; i++) {
      idx = hash_i(key, i) % capacity;
      if (table[idx].state == EMPTY) break;
  }
 ```

方法4：建立公共溢出区

```
基本区                          溢出区
  ┌───┬───┬───┬───┐              ┌───┬───┬───┬───┐
  │ A │ B │ C │   │  冲突元素 →  │ D │ E │ F │   │
  └───┴───┴───┴───┘              └───┴───┴───┴───┘

  查找时：先查基本区，再查溢出区
```
