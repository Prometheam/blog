claude使用心得

#### 配置 Playwright，让claude具备浏览器自动化能力

配置 Playwright MCP：
  `claude mcp add playwright -- npx @playwright/mcp@latest`
  如果想用有头模式（能看到浏览器界面），添加 --headed 参数：
  `claude mcp add playwright -- npx @playwright/mcp@latest --headed`
  添加后重启 Claude Code 会话，再运行 /mcp 就能看到已配置的服务器
	
	说明：@playwright/mcp 是微软官方发布在 npm 上的包，npx 会自动从 npm 拉取并执行
