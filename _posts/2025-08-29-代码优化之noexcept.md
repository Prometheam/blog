<p style=""><code>noexcept</code> 是 C++11 引入的关键字，用于指定函数是否会抛出异常。它的主要作用是:</p><p style="">1. **性能优化**：编译器可能为 <code>noexcept</code> 函数生成更高效的代码（如省略异常处理逻辑）。</p><p style="">2. **移动语义**：标准库（如 <code>std::vector</code>）在扩容时，若元素类型的移动操作是 <code>noexcept</code>，会优先使用移动而非复制。</p><p style="">3. **契约声明**：明确告知调用者函数不会抛出异常，简化错误处理。</p><p style="">- **作为说明符（Specifier）**：声明函数不会抛出异常</p><pre><code>  void func() noexcept {

      // 如果此处抛出异常，程序会调用 std::terminate()

  }</code></pre><p style="">  - **条件性 <code>noexcept</code>**（C++11 起）：</p><p style="">    ```</p><p style="">    void bar() noexcept(true);  // 等价于 noexcept</p><p style="">    void baz() noexcept(false); // 可能抛出异常</p><p style="">    ```</p><p style="">  - **模板中的条件 <code>noexcept</code>**：</p><p style="">    ```</p><p style="">    template&lt;typename T&gt;</p><p style="">    void swap(T&amp; a, T&amp; b) noexcept(noexcept(a.swap(b))) {</p><p style="">        a.swap(b); // 仅当 a.swap(b) 不抛异常时，整个函数才是 noexcept</p><p style="">    }</p><p style="">    ```</p><p style="">    </p><p style="">- **作为运算符（Operator）**：检查表达式是否声明为 <code>noexcept</code>，返回 <code>bool</code>。</p><p style="">  ```</p><p style="">  bool is_noexcept = noexcept(func());  // 检查 func() 是否声明为 noexcept</p><p style="">  ```</p><p style="">  </p>
