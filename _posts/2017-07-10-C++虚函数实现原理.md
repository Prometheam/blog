&ensp;&ensp;&ensp;&ensp;C++ 中的虚函数（Virtual Function）通过**虚函数表（Virtual Table, vtable）**和**虚指针（vptr）**机制实现多态，其核心原理如下：



### **1. 虚函数表（vtable）**

- **每个包含虚函数的类**（或继承自含虚函数的类）会生成一个虚函数表，表中按声明顺序存储该类的所有虚函数的地址。

- **虚函数表是类级别的**，所有该类的对象共享同一份虚函数表。

  ```
  class Base {
  public:
      virtual void func1() {}
      virtual void func2() {}
  };
  
  Base obj1, obj2;  // obj1 和 obj2 的 vptr 指向同一个虚函数表（Base 的 vtable）
  ```

  

- 若子类重写（override）父类的虚函数，则子类的虚函数表中对应位置替换为子类的函数地址；未重写的虚函数保留父类的实现地址。

  ```
  class Base {
  public:
      virtual void func1() {}  // 虚函数
      virtual void func2() {}
  };
  class Derived : public Base {
  public:
      void func1() override {} // 重写 func1
      // func2 未重写，保留 Base 的实现
  };
  ```

  - `Base` 的虚函数表：`[ &Base::func1, &Base::func2 ]`
  - `Derived` 的虚函数表：`[ &Derived::func1, &Base::func2 ]`

### **2. 虚指针（vptr）**

- **每个对象内部**（通常位于对象内存布局的开头）隐藏一个指向虚函数表的指针（`vptr`）。
- 当对象被构造时，编译器自动将vptr指向正确的虚函数表：
  - `Base` 对象的 `vptr` 指向 `Base` 的虚函数表。
  - `Derived` 对象的 `vptr` 指向 `Derived` 的虚函数表。

**内存布局示意：**

```
Derived 对象:
+----------------+
| vptr           | --> Derived的vtable [ &Derived::func1, &Base::func2 ]
| Base类成员数据  |
| Derived类成员数据|
+----------------+
```

### **3. 动态绑定的实现**

当通过**基类指针或引用**调用虚函数时：

1. 通过对象的 `vptr` 找到虚函数表。

2. 从虚函数表中取出对应的函数地址。

3. 调用该地址的函数。

   ```
   Base* obj = new Derived();
   obj->func1(); // 实际调用 Derived::func1()
   ```
