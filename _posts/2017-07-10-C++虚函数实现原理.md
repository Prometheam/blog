&ensp;&ensp;&ensp;&ensp;C++ 中的虚函数（Virtual Function）通过**虚函数表（Virtual Table, vtable）**和**虚指针（vptr）**机制实现多态，其核心原理如下：



### **1. 虚函数表（vtable）**

- **每个包含虚函数的类**（或继承自含虚函数的类）会生成一个虚函数表，表中按声明顺序存储该类的所有虚函数的地址。

- **虚函数表是类级别的**，所有该类的对象共享同一份虚函数表。

  ```
  class Base {
  public:
      virtual void func1() {}
      virtual void func2() {}
  };
  
  Base obj1, obj2;  // obj1 和 obj2 的 vptr 指向同一个虚函数表（Base 的 vtable）
  ```

  

- 若子类重写（override）父类的虚函数，则子类的虚函数表中对应位置替换为子类的函数地址；未重写的虚函数保留父类的实现地址。

  ```
  class Base {
  public:
      virtual void func1() {}  // 虚函数
      virtual void func2() {}
  };
  class Derived : public Base {
  public:
      void func1() override {} // 重写 func1
      // func2 未重写，保留 Base 的实现
  };
  ```

  - `Base` 的虚函数表：`[ &Base::func1, &Base::func2 ]`
  - `Derived` 的虚函数表：`[ &Derived::func1, &Base::func2 ]`

- 类之间存在集成关系

  - #### **1. 单继承**

    - **基类有虚函数**：派生类共享基类的虚函数表，若派生类新增虚函数，会**扩展**该表。
    - **结果**：始终 **1个虚函数表**。

  - #### **2. 多重继承**

    - **每个有虚函数的基类贡献一个虚函数表**。
    - 派生类：
      - 若**新增虚函数**：通常附加到**第一个基类的虚函数表**中（编译器相关）。
      - 若**覆盖虚函数**：替换对应基类虚函数表中的条目。

    ```
    class Base1 { virtual void f1(); };
    class Base2 { virtual void f2(); };
    class Derived : public Base1, public Base2 { virtual void fd(); };
    ```

    - **虚函数表数量**：2个（`Base1`和`Base2`各一个）。
    - `Derived::fd` 可能被放入 `Base1` 的虚函数表中。

  - #### **3. 菱形继承（虚继承）**

    - **虚基类**会引入额外的虚函数表或偏移信息（编译器实现依赖）。

    ```
    class Base { virtual void f(); };
    class D1 : virtual public Base {};
    class D2 : virtual public Base {};
    class Final : public D1, public D2 {};
    ```

    - **虚函数表数量**：通常为3个（`D1`、`D2`各一个，`Base`一个共享表）。
    - 虚继承通过**虚基类指针**（vptr）实现，可能增加额外开销。

### **2. 虚指针（vptr）**

- **每个对象内部**（通常位于对象内存布局的开头）隐藏一个指向虚函数表的指针（`vptr`）。
- 当对象被构造时，编译器自动将vptr指向正确的虚函数表：
  - `Base` 对象的 `vptr` 指向 `Base` 的虚函数表。
  - `Derived` 对象的 `vptr` 指向 `Derived` 的虚函数表。

**内存布局示意：**

```
Derived 对象:
+----------------+
| vptr           | --> Derived的vtable [ &Derived::func1, &Base::func2 ]
| Base类成员数据  |
| Derived类成员数据|
+----------------+
```

### **3. 动态绑定的实现**

当通过**基类指针或引用**调用虚函数时：

1. 通过对象的 `vptr` 找到虚函数表。

2. 从虚函数表中取出对应的函数地址。

3. 调用该地址的函数。

   ```
   Base* obj = new Derived();
   obj->func1(); // 实际调用 Derived::func1()
   ```
