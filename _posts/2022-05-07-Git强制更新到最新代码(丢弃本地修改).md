&ensp;&ensp;&ensp;&ensp;要将本地 Git 仓库强制更新到远程仓库的最新状态（丢弃所有本地修改），请按以下步骤操作：

1. 切换到目标分支（如 gh-pages）

	```
	git checkout gh-pages  # 如果已在当前分支可跳过
	```

2. 重置本地分支到远程最新状态

	```
	git fetch --all         # 获取远程所有最新数据
	git reset --hard origin/gh-pages  # 强制重置到远程分支	
	```

3. 清理未跟踪文件（可选）

	```
	git clean -fd  # 删除所有未跟踪的文件和目录
	```
