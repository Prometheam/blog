<p style=""><code>explicit</code><span style="font-size: 14px; color: rgb(0, 0, 0)"> 是一个关键字，主要用于 C++ 语言中，用于<strong>修饰类的构造函数</strong>。它的作用是防止编译器进行隐式的类型转换，从而避免潜在的错误或歧义。</span></p><h3 style="" id="%E4%BD%9C%E7%94%A8%EF%BC%9A"><strong>作用：</strong></h3><ol><li><p style="line-height: 1.6"><strong>禁止隐式转换</strong>：<br>当构造函数被声明为 <code>explicit</code> 时，编译器不会自动调用该构造函数进行隐式类型转换，必须显式地调用构造函数。</p></li><li><p style="line-height: 1.6"><strong>避免意外的行为</strong>：<br>某些情况下，隐式转换可能导致逻辑错误或难以发现的 bug。<code>explicit</code> 强制要求程序员明确表达意图。</p></li></ol><h3 style="" id="%E7%A4%BA%E4%BE%8B%EF%BC%9A"><strong>示例：</strong></h3><pre><code>class MyClass {
public:
    explicit MyClass(int x) { 
        // 构造函数逻辑
    }
};

void func(MyClass obj) {}

int main() {
    // MyClass obj = 10;  // 错误：explicit 禁止隐式转换
    MyClass obj(10);      // 正确：显式调用构造函数
    func(MyClass(20));    // 正确：显式转换
    // func(30);          // 错误：不能隐式转换 int 到 MyClass
    return 0;
}</code></pre><h3 style="" id="%E9%80%82%E7%94%A8%E5%9C%BA%E6%99%AF%EF%BC%9A"><strong>适用场景：</strong></h3><ul><li><p style=""><strong>单参数构造函数</strong>：<br>如果构造函数只有一个参数（或多个参数但有默认值），通常建议用 <code>explicit</code> 避免隐式转换。</p></li><li><p style=""><strong>避免歧义</strong>：<br>例如 <code>std::vector</code> 的构造函数 <code>explicit vector(size_type count)</code> 防止误写为 <code>vector&lt;int&gt; v = 5</code>。</p></li></ul><p style=""></p>
