<p style="">&amp;ensp;&amp;ensp;&amp;ensp;&amp;ensp; <code>std::function</code> 是 C++ 标准库（C++11 引入）中的一个通用 <strong>函数包装器</strong>，它可以存储、复制和调用各种 <strong>可调用对象</strong>（如普通函数、Lambda 表达式、函数对象、成员函数等）。它是 `` 头文件的一部分，常用于实现 <strong>回调机制、事件处理、策略模式</strong> 等场景。</p><p style="">		#### 1.基本语法</p><p style="">```</p><p style="">#include &lt;functional&gt;</p><p style="">std::function&lt;返回值类型(参数类型1, 参数类型2, ...)&gt; 变量名;</p><p style="">//示例：</p><p style="">std::function&lt;int(int, int)&gt; func;  // 声明一个接收两个int参数、返回int的可调用对象包装器</p><p style="">```</p><p style="">#### 2.能存储哪些对象？</p><p style="">- 1.存储普通函数</p><p style="">  ```</p><p style="">  #include &lt;functional&gt;</p><p style="">  #include &lt;iostream&gt;</p><p style="">  </p><p style="">  int add(int a, int b) {</p><p style="">      return a + b;</p><p style="">  }</p><p style="">  </p><p style="">  int main() {</p><p style="">      std::function&lt;int(int, int)&gt; func = add;</p><p style="">      std::cout &lt;&lt; func(2, 3);  // 输出: 5</p><p style="">      return 0;</p><p style="">  }</p><p style="">  ```</p><p style="">- 2.存储Lambda表达式</p><p style="">  ```</p><p style="">  int main() {</p><p style="">      std::function&lt;int(int, int)&gt; func = [](int a, int b) {</p><p style="">          return a * b;</p><p style="">      };</p><p style="">      std::cout &lt;&lt; func(3, 4);  // 输出: 12</p><p style="">      return 0;</p><p style="">  }</p><p style="">  ```</p><p style="">- 3.存储函数对象(仿函数)</p><p style="">  ```</p><p style="">  struct Multiply {</p><p style="">      int operator()(int a, int b) {</p><p style="">          return a * b;</p><p style="">      }</p><p style="">  };</p><p style="">  </p><p style="">  int main() {</p><p style="">      std::function&lt;int(int, int)&gt; func = Multiply();</p><p style="">      std::cout &lt;&lt; func(3, 5);  // 输出: 15</p><p style="">      return 0;</p><p style="">  }</p><p style="">  ```</p><p style="">- 4.存储成员函数(需绑定对象)</p><p style="">  ```</p><p style="">  class Math {</p><p style="">  public:</p><p style="">      int subtract(int a, int b) {</p><p style="">          return a - b;</p><p style="">      }</p><p style="">  };</p><p style="">  </p><p style="">  int main() {</p><p style="">      Math math;</p><p style="">      // 使用 std::bind 绑定对象和成员函数</p><p style="">      std::function&lt;int(int, int)&gt; func = std::bind(&amp;Math::subtract, &amp;math, std::placeholders::_1, std::placeholders::_2);</p><p style="">      std::cout &lt;&lt; func(10, 4);  // 输出: 6</p><p style="">      return 0;</p><p style="">  }</p><p style="">  ```</p><p style="">  </p><p style="">- 5.静态成员函数</p><p style="">  ```</p><p style="">  #include &lt;functional&gt;</p><p style="">  #include &lt;iostream&gt;</p><p style="">  </p><p style="">  class Math { </p><p style="">      public:</p><p style="">      static int divide(int a, int b){return a-b;} </p><p style="">  };</p><p style="">  </p><p style="">  int main() {</p><p style="">      std::function&lt;int(int, int)&gt; func = Math::divide;</p><p style="">      std::cout &lt;&lt; func(3, 3);  // 输出: 5</p><p style="">      return 0;</p><p style="">  }</p><p style="">  ```</p>
