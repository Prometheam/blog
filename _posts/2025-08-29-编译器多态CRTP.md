<p style="text-indent: 2em">CRTP (Curiously Recurring Template Pattern) 奇异递归模板模式- 编译期多态是一种C++模板编程技术，用于实现编译期多态（静态多态），与运行时多态（通过虚函数实现）形成对比。</p><p style="">#### 1、CRTP的核心思想是：</p><p style="">一个类派生自一个以自身为模板参数的模板基类。</p><p style="">```</p><p style="">template &lt;typename Derived&gt;</p><p style="">class Base {</p><p style="">    // ...</p><p style="">};</p><p style="">class Derived : public Base&lt;Derived&gt; {</p><p style="">    // ...</p><p style="">};</p><p style="">```</p><p style="">#### 2、工作原理</p><p style="">1. <strong>模板基类</strong>：接受派生类类型作为模板参数</p><p style="">2. <strong>派生类</strong>：继承自以自身为模板参数的基类</p><p style="">3. <strong>静态多态</strong>：通过静态转换实现方法调用，无需虚函数开销</p><p style="">#### 3、典型应用场景</p><p style="">- 静态多态（编译期多态）</p><p style="">  ```</p><p style="">  template &lt;typename Derived&gt;</p><p style="">  class Animal {</p><p style="">  public:</p><p style="">      void speak() {</p><p style="">          static_cast&lt;Derived*&gt;(this)-&gt;speakImpl();</p><p style="">      }</p><p style="">  };</p><p style="">  </p><p style="">  class Dog : public Animal&lt;Dog&gt; {</p><p style="">  public:</p><p style="">      void speakImpl() {</p><p style="">          std::cout &lt;&lt; "Woof!" &lt;&lt; std::endl;</p><p style="">      }</p><p style="">  };</p><p style="">  </p><p style="">  class Cat : public Animal&lt;Cat&gt; {</p><p style="">  public:</p><p style="">      void speakImpl() {</p><p style="">          std::cout &lt;&lt; "Meow!" &lt;&lt; std::endl;</p><p style="">      }</p><p style="">  };</p><p style="">  ```</p><p style="">  </p><p style="">- 对象计数器</p><p style="">  ```</p><p style="">  template &lt;typename T&gt;</p><p style="">  class Counter {</p><p style="">      static int count;</p><p style="">  public:</p><p style="">      Counter() { ++count; }</p><p style="">      ~Counter() { --count; }</p><p style="">      static int getCount() { return count; }</p><p style="">  };</p><p style="">  </p><p style="">  template &lt;typename T&gt;</p><p style="">  int Counter&lt;T&gt;::count = 0;</p><p style="">  </p><p style="">  class Widget : public Counter&lt;Widget&gt; {</p><p style="">      // ...</p><p style="">  };</p><p style="">  ```</p><p style="">  </p><p style="">- 链式调用</p><p style="">  ```</p><p style="">  template &lt;typename Derived&gt;</p><p style="">  class Chainable {</p><p style="">  public:</p><p style="">      Derived&amp; setX(int x) {</p><p style="">          static_cast&lt;Derived*&gt;(this)-&gt;x = x;</p><p style="">          return <em>static_cast&lt;Derived</em>&gt;(this);</p><p style="">      }</p><p style="">      Derived&amp; setY(int y) {</p><p style="">          static_cast&lt;Derived*&gt;(this)-&gt;y = y;</p><p style="">          return <em>static_cast&lt;Derived</em>&gt;(this);</p><p style="">      }</p><p style="">  };</p><p style="">  </p><p style="">  class Point : public Chainable&lt;Point&gt; {</p><p style="">  public:</p><p style="">      int x, y;</p><p style="">  };</p><p style="">  </p><p style="">  // 使用</p><p style="">  Point p;</p><p style="">  p.setX(10).setY(20);</p><p style="">  ```</p><p style="">  </p><p style="">#### 4、优点</p><p style="">1. <strong>无虚函数开销</strong>：避免了虚函数调用的运行时开销</p><p style="">2. <strong>编译期绑定</strong>：所有方法调用在编译期确定</p><p style="">3. <strong>更好的性能</strong>：适合性能敏感的场景</p><p style="">4. <strong>更灵活的设计</strong>：可以在编译期实现多态</p>
