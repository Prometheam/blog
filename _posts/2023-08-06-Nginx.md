#### Nginx

高性能的Web服务器、反向代理服务器和负载均衡器。

#### 核心架构设计

1. Nginx采用**主-从进程模型**

   Master进程：root权限运行，不直接处理客户端请求，主要负责管理worker进程、读取和验证配置、绑定端口、平滑升级和重启、日志处理等

   Worker进程：普通用户权限运行，实际处理客户端的请求，每个worker都是单线程

   `worker_processes auto;  # 自动设置为CPU核心数`

2. 事件驱动架构

   Nginx使用异步非阻塞I/O模型：

   - 基于事件通知机制(Linux下使用epoll，FreeBSD使用kqueue)

   - 单worker可同时处理数千个链接

   - 无线程上下文切换开销

     ```
     events {
         use epoll;          # Linux 事件模型
         worker_connections 1024;  # 每个worker的最大连接数
         multi_accept on;    # 一次accept多个连接
     }
     ```
