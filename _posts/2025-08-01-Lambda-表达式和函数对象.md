在 C++ 中，Lambda 表达式和函数对象（Function Objects，也称为仿函数/Functors） 都是可调用对象（Callable Objects）的实现方式，用于定义可被调用的行为。

#### 1.函数对象 通过重载 operator() 运算符的类实例，可以像函数一样被调用。
	
```
// 定义函数对象类
	struct Adder {
	    int base;  // 状态
	    Adder(int n) : base(n) {}
	    // 重载函数调用运算符
	    int operator()(int x) const {
	        return base + x;
	    }
	};
	int main() {
	    Adder add5(5);  // 创建函数对象
	    std::cout &lt;&lt; add5(3);  // 输出 8 (5+3)
	    Adder add10(10);
	    std::cout &lt;&lt; add10(3); // 输出 13 (10+3)
	}
```
		
		
#### 2. Lambda 表达式
基本语法：
[捕获列表](参数列表) -&gt; 返回类型 { 函数体 }
```
// 定义 lambda 表达式
	int base = 5;
	auto add = [base](int x) { 

	    return base + x; 

	};
	std::cout &lt;&lt; add(3);  // 输出 8
```

#### 3.Lambda 表达式的本质是编译器生成的匿名函数对象（仿函数）。

  当你写：

```
	int x = 10;
  	auto f = [x](int a) { return a + x; };
```

  编译器大致等价生成：

  ```
class __UniqueClosureType {
      int x;  // 捕获的变量变成成员
  public:
      __UniqueClosureType(int x) : x(x) {}
      int operator()(int a) const { return a + x; }
  };
  auto f = __UniqueClosureType(x);
```

  几个关键点：

  - 闭包类：编译器为每个 lambda 生成一个唯一的未命名类，类名你无法直接写出。
  - 闭包对象：lambda 表达式求值后产生的就是这个类的实例。
  - 捕获 = 成员变量：值捕获相当于拷贝初始化成员，引用捕获相当于引用成员。
  - operator()：函数体就是重载的调用运算符，默认 const，加 mutable 才去掉。
  - 无捕获的 lambda 可以转换为函数指针：因为它没有状态，operator() 等价于普通函数。

  所以 lambda 不是函数，不是函数指针，而是一个带状态的、编译器帮你写好的仿函数。它的价值在于让你不用手动定义类就能在局部创建可调用对象。
