<p style="text-indent: 2em">在 C++ 中，Lambda 表达式和函数对象（Function Objects，也称为仿函数/Functors） 都是可调用对象（Callable Objects）的实现方式，用于定义可被调用的行为。</p><h3 style="" id="1.%E5%87%BD%E6%95%B0%E5%AF%B9%E8%B1%A1">1.函数对象</h3><p style="">通过重载 operator() 运算符的类实例，可以像函数一样被调用。</p><pre><code>	// 定义函数对象类
	struct Adder {
	    int base;  // 状态
	    Adder(int n) : base(n) {}
	    // 重载函数调用运算符
	    int operator()(int x) const {
	        return base + x;
	    }
	};
	int main() {
	    Adder add5(5);  // 创建函数对象
	    std::cout &lt;&lt; add5(3);  // 输出 8 (5+3)
	    Adder add10(10);
	    std::cout &lt;&lt; add10(3); // 输出 13 (10+3)
	}</code></pre><h3 style="" id="2.-lambda-%E8%A1%A8%E8%BE%BE%E5%BC%8F">2. Lambda 表达式</h3><p style="">基本语法：</p><p style="">	[捕获列表](参数列表) -&gt; 返回类型 { 函数体 }</p><p style="">示例：</p><pre><code>	int base = 5;

	

	// 定义 lambda 表达式

	auto add = [base](int x) { 

	    return base + x; 

	};
	std::cout &lt;&lt; add(3);  // 输出 8</code></pre><p style="">	</p><p style=""></p>
