<h3 style="" id="c%E4%B8%AD%E7%9A%84%E7%B1%BB%E5%9E%8B%E8%BD%AC%E6%8D%A2">C中的类型转换</h3><p style="text-indent: 2em">在 C 语言中，类型转换（Type Casting）用于显式或隐式地将一种数据类型转换为另一种数据类型。由于 C 语言是弱类型语言，类型转换更加灵活，但也更容易引发潜在的错误</p><h4 style="" id="1.-%E9%9A%90%E5%BC%8F%E7%B1%BB%E5%9E%8B%E8%BD%AC%E6%8D%A2%EF%BC%88%E8%87%AA%E5%8A%A8%E8%BD%AC%E6%8D%A2%EF%BC%89">1. 隐式类型转换（自动转换）</h4><p style="">编译器在表达式求值时自动进行类型转换，规则如下：</p><ul><li><p style="">整型提升（Integer Promotion）：char、short 等小于 int 的类型在运算时自动提升为 int 或 unsigned int。</p></li><li><p style="">算术转换（Usual Arithmetic Conversions）：</p><ul><li><p style="">如果运算涉及不同数据类型，较低精度的类型会转换为较高精度的类型：</p></li><li><p style="">有符号和无符号混合时，有符号类型可能被转换为无符号类型（可能导致意外行为）。</p></li></ul></li></ul><pre><code>int + float → float

float + double → double</code></pre><p style="margin-left: 24px!important; text-indent: 2em"></p><p style="">示例：</p><pre><code>int a = 10;

float b = 3.14;

float c = a + b; // a 自动转换为 float</code></pre><h4 style="" id="2.-%E6%98%BE%E5%BC%8F%E7%B1%BB%E5%9E%8B%E8%BD%AC%E6%8D%A2%EF%BC%88%E5%BC%BA%E5%88%B6%E8%BD%AC%E6%8D%A2%EF%BC%89">2. 显式类型转换（强制转换）</h4><p style="">使用 (type) 语法进行强制转换，类似于 C++ 的 static_cast，但不进行安全性检查。</p><p style="">语法：</p><pre><code>(target_type) expression</code></pre><p style="">示例：</p><pre><code>int x = 10;

double y = (double)x; // int → double

float f = 3.14;

int i = (int)f; // float → int（截断小数部分，i=3）

int* p = (int*)malloc(sizeof(int)); // void* → int*</code></pre><h4 style="" id="3.-%E6%8C%87%E9%92%88%E7%B1%BB%E5%9E%8B%E8%BD%AC%E6%8D%A2">3. 指针类型转换</h4><p style="">C 语言允许任意指针类型之间的强制转换，但极其危险：</p><ul><li><p style="">void* 与其他指针类型的转换：malloc 返回 void*，通常需要强制转换：</p></li></ul><pre><code>int* arr = (int*)malloc(10 * sizeof(int));</code></pre><ul><li><p style="">无关指针类型的转换：</p></li></ul><pre><code>int x = 65;

char* c = (char*)&amp;x; // int* → char*（访问 x 的字节）

printf("%c", *c); // 输出 'A'（ASCII 65）</code></pre><p style="text-indent: 2em">这种转换可能导致未定义行为（如对齐问题、非法访问）。</p><h4 style="" id="4.-%E7%BB%93%E6%9E%84%E4%BD%93%E7%B1%BB%E5%9E%8B%E8%BD%AC%E6%8D%A2">4. 结构体类型转换</h4><p style="">C 语言不允许直接转换结构体类型，但可以通过内存拷贝实现：</p><pre><code>

struct A { int x; };

struct B { int y; };

struct A a = {10};

struct B b;

memcpy(&amp;b, &amp;a, sizeof(a)); // 内存拷贝（危险！需确保布局一致）</code></pre><p style=""></p><h3 style="" id="c%2B%2B%E4%B8%AD%E7%9A%84%E7%B1%BB%E5%9E%8B%E8%BD%AC%E6%8D%A2">C++中的类型转换</h3><p style="text-indent: 2em">在 C++ 中，类型转换（Type Casting）是显式地将一种数据类型转换为另一种数据类型的操作。C++ 提供了四种主要的类型转换运算符，每种都有特定的用途和安全性保证，比 C 语言的强制转换更安全、更明确。以下是 C++ 中类型转换的详细说明：</p><h4 style="" id="1.-static_cast">1. static_cast</h4><p style=""><strong>用途</strong></p><p style="text-indent: 2em">用于相关类型之间的安全转换，编译器会进行类型检查。</p><p style="text-indent: 2em">不能用于无关类型的指针转换（如 int* → double*）。</p><p style=""><strong>常见场景</strong></p><p style="text-indent: 2em">基本数据类型转换（如 int → double）：</p><pre><code>int a = 10;

double b = static_cast&lt;double&gt;(a); // int → double</code></pre><p style="text-indent: 2em">类层次中的向上转换（派生类 → 基类）：</p><pre><code>

class Base {};

class Derived : public Base {};

Derived d;

Base* b = static_cast&lt;Base*&gt;(&amp;d); // 安全，向上转换</code></pre><p style="text-indent: 2em">显式调用构造函数或转换函数：</p><pre><code>class MyClass {

public:

    explicit MyClass(int x) {}

};

MyClass obj = static_cast&lt;MyClass&gt;(42); // 显式调用构造函数</code></pre><p style=""></p><p style=""><strong>特点</strong></p><p style="text-indent: 2em">编译时检查，无运行时开销。</p><p style="text-indent: 2em">不能用于多态类型的向下转换（需用 dynamic_cast）。</p><h4 style="" id="2.-dynamic_cast">2. dynamic_cast</h4><p style=""><strong>用途</strong></p><p style="text-indent: 2em">主要用于多态类层次中的向下转换（基类 → 派生类）。</p><p style="text-indent: 2em">运行时检查：如果转换失败，指针返回 nullptr，引用抛出 std::bad_cast。</p><p style=""><strong>常见场景</strong></p><pre><code>

class Base { virtual void foo() {} }; // 必须有虚函数

class Derived : public Base {};

Base* base_ptr = new Derived;

Derived* derived_ptr = dynamic_cast&lt;Derived*&gt;(base_ptr); // 向下转换

if (derived_ptr) { /* 转换成功 */ }</code></pre><p style=""><strong>特点</strong></p><p style="text-indent: 2em">需要基类有虚函数（即多态类型）。</p><p style="text-indent: 2em">有运行时开销（检查类型信息）。</p><h4 style="" id="3.-const_cast">3. const_cast</h4><p style=""><strong>用途</strong></p><p style="text-indent: 2em">用于修改类型的 const 或 volatile 属性。</p><p style="text-indent: 2em">不能改变数据类型，仅用于去除或添加 const/volatile。</p><p style=""><strong>常见场景</strong></p><p style="text-indent: 2em">去除 const 限定符（谨慎使用）：</p><pre><code>const int x = 10;

int* p = const_cast&lt;int*&gt;(&amp;x); // 去除 const

*p = 20; // 未定义行为（原对象可能是只读内存）</code></pre><p style="text-indent: 2em">调用旧式 C 函数：</p><pre><code>void legacy_func(char* str);

const char* msg = "hello";

legacy_func(const_cast&lt;char*&gt;(msg)); // 临时去除 const</code></pre><p style=""><strong>特点</strong></p><p style="text-indent: 2em">滥用可能导致未定义行为（如修改真正的常量）。</p><h4 style="" id="4.-reinterpret_cast">4. reinterpret_cast</h4><p style=""><strong>用途</strong></p><p style="text-indent: 2em">用于无关类型之间的低级别重新解释（直接操作二进制位）。</p><p style="text-indent: 2em">最不安全的转换，通常用于底层编程（如硬件访问、数据序列化）。</p><p style=""><strong>常见场景</strong></p><p style="text-indent: 2em">指针类型之间的转换：</p><pre><code>int* p = new int(65);

char* c = reinterpret_cast&lt;char*&gt;(p); // int* → char*

std::cout &lt;&lt; *c; // 输出 'A'（ASCII 65）</code></pre><p style=""></p><p style="text-indent: 2em">整数与指针之间的转换：</p><pre><code>uintptr_t addr = 0x1234;

void* ptr = reinterpret_cast&lt;void*&gt;(addr); // 整数 → 指针</code></pre><p style=""></p><p style=""><strong>特点</strong></p><p style="text-indent: 2em">不进行任何类型检查，完全依赖程序员保证安全。</p><p style="text-indent: 2em">可能导致未定义行为（如对齐问题）。</p><h3 style="" id="%E6%80%BB%E7%BB%93%EF%BC%9A">总结：</h3><ol><li><p style="">优先使用 static_cast：适用于大多数安全转换场景。</p></li><li><p style="">多态类型向下转换用 dynamic_cast：确保运行时安全。</p></li><li><p style="">避免 const_cast 和 reinterpret_cast：除非必须且明确安全。</p></li><li><p style="">彻底废弃 C 风格强制转换：改用 C++ 的类型转换运算符。</p></li></ol><p style=""></p>
