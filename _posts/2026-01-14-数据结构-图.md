抽空来系统地复盘一下数据结构中的“图”。

图是一种非常重要的**非线性数据结构**，用于表示物体（顶点）和它们之间的关系（边）。它是比线性表和树更复杂、更一般化的结构。

### 一、核心概念

1. **顶点**：也称为“节点”，是图的基本单位，用于表示实体。
2. **边**：连接两个顶点的线，表示实体之间的关系。边可以是有方向的，也可以是无方向的。
3. **图 G** 可以形式化地定义为由两个集合组成：`G = (V, E)`。
   * **V** 是顶点的有限非空集合。
   * **E** 是边的集合，边是顶点对 `(v, w)`，其中 `v, w ∈ V`。

### 二、图的分类

根据边的不同属性，图可以分为以下几类：

| 类型             | 特点                                               | 示例                                          |
| ---------------- | -------------------------------------------------- | --------------------------------------------- |
| **无向图** | 边没有方向，`(A, B)`表示 A 和 B 是相连的，互通。 | 社交网络中的好友关系（互为好友）。            |
| **有向图** | 边有方向，\`\` 表示从 A 指向 B，关系是单向的。     | 微博的关注关系（A 关注 B，不代表 B 关注 A）。 |
| **加权图** | 边被赋予一个数值（权重），表示距离、成本、流量等。 | 地图上城市间的距离或行车时间。                |
| **无权图** | 所有边没有权重，只表示连接与否。                   | 人际关系网。                                  |

**特殊概念**：

* **度**：
  * **无向图**：一个顶点的度是指与其相连的边的数量。
  * **有向图**：分为**入度**（指向该顶点的边数）和**出度**（从该顶点指出的边数）。
* **路径**：从一个顶点到另一个顶点经过的顶点序列。
* **环**：起点和终点相同的路径。
* **连通图**（无向图）：图中任意两个顶点都有路径相连。
* **强连通图**（有向图）：图中任意两个顶点都存在**双向**的路径。

### 三、图的存储（表示）方式

在计算机中，图主要有两种存储方式：

| 存储方式           | 描述                                                                                                            | 优点                                                                     | 缺点                                                               | 适用场景                         |
| ------------------ | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------ | -------------------------------- |
| **邻接矩阵** | 使用一个 `V x V`的二维数组 `matrix`。`matrix[i][j] = 1`（或权重值）表示顶点 i 到 j 有边；`=0`表示无边。 | **实现简单**；**快速判断**任意两顶点间是否有边；适合稠密图。 | **空间复杂度高** `O(V²)`；**添加/删除顶点**开销大。 | 顶点数较少，或边非常多的图。     |
| **邻接表**   | 为每个顶点维护一个链表（或数组），存储所有与其直接相连的顶点（及权重）。                                        | **空间效率高** `O(V+E)`；**易于遍历**某顶点的所有邻居。    | **判断两顶点是否相邻**效率较低 `O(degree(v))`。            | 实际应用中最常用，尤其是稀疏图。 |

**直观对比**：对于一个无向图：

```
A -- B
| \
C   D
```

* **邻接矩阵**：
  ```
    A B C D
  A 0 1 1 1
  B 1 0 0 0
  C 1 0 0 0
  D 1 0 0 0
  ```
* **邻接表**：
  ```
  A -> [B, C, D]
  B -> [A]
  C -> [A]
  D -> [A]
  ```

### 四、图的基本操作与遍历

图的遍历是图算法的基础，指从图中某一顶点出发，系统地访问图中所有顶点，且每个顶点只访问一次。

1. **深度优先搜索**
   * **思想**：类似“走迷宫”，沿着一条路径一直深入，直到走不通再回溯。
   * **数据结构**：使用**栈**（递归或显式栈）。
   * **特点**：可能**更快地到达深层节点**。常用于**拓扑排序、寻找连通分量、解决回溯问题**等。
2. **广度优先搜索**
   * **思想**：类似“水波扩散”，从起点开始，一层一层地向外探索。
   * **数据结构**：使用**队列**。
   * **特点**：**保证找到的路径是最短路径**（对无权图而言）。常用于**寻找最短路径、社交网络中的“朋友的朋友”**等。

### 五、经典图算法简介

* **最短路径问题**：
  * **Dijkstra算法**：解决**单源最短路径**（加权图，权重非负）。
  * **Bellman-Ford算法**：解决单源最短路径（允许负权重边，能检测负权环）。
  * **Floyd-Warshall算法**：解决**所有顶点对**之间的最短路径。
* **最小生成树**：在一个加权连通无向图中，找到一个边的子集，能连接所有顶点，且总权重最小。
  * **Prim算法**：从一个顶点开始，逐步“生长”出一棵树。
  * **Kruskal算法**：按权重从小到大选择边，确保不形成环。
* **拓扑排序**：针对**有向无环图**，将所有顶点排成一个线性序列，使得对任何有向边 `(u, v)`，u 在序列中都出现在 v 之前。用于任务调度、课程安排。

### 六、图的应用场景

* **社交网络**：用户是顶点，关注/好友关系是边。推荐好友（BFS），影响力分析。
* **地图与导航**：路口是顶点，道路是边（权重为时间/距离）。路径规划（Dijkstra算法）。
* **网络拓扑**：路由器/服务器是顶点，物理链路是边。分析网络结构，寻找关键节点。
* **知识图谱**：实体是顶点，关系是边。用于语义搜索、智能问答。
* **依赖关系**：软件包、任务之间的依赖构成有向图。解决依赖冲突、安装顺序（拓扑排序）。
