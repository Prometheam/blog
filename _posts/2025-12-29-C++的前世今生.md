#**C++98（ISO/IEC 14882:1998）**

C++98 是 C++ 的第一个标准化版本（ISO/IEC 14882:1998），它正式确立了 C++ 的核心语言特性和标准库。以下是 C++98 的主要特性总结：

### 一、核心语言特性**

1. **模板（Templates）**

- 支持函数模板和类模板，实现泛型编程。

- 例如 等标准库组件依赖模板。

2. **标准模板库（STL）**

- 包含容器（如 ）、迭代器（iterators）和算法（如 ）。

- 基于泛型编程思想，强调“数据与算法分离”。

3. **异常处理（Exception Handling）**

- 引入  机制，支持错误处理的标准化。

4. **命名空间（Namespaces）**

- 避免命名冲突，例如  是标准库的命名空间。

5. **RTTI（运行时类型识别）**

- 支持  和 ，允许在运行时检查类型。

6. **bool 类型**

- 引入  关键字），取代传统的  表示布尔值。

7. **mutable 关键字**

- 允许在  成员函数中修改被标记为  的成员变量。

8. **显式类型转换**

- 提供 ，替代 C 风格的强制转换。

9. **默认参数和函数重载**

- 支持函数参数的默认值和函数重载（相同函数名，不同参数列表）。

------

### **二、标准库组件**

1. **容器（Containers）**

- 序列容器

- 关联容器

- 适配器

2. **迭代器（Iterators）**

- 提供统一的遍历容器元素的接口（如 ）。

3. **算法（Algorithms）**

- 如  等，通过迭代器操作容器。

4. **字符串类（std::string）**

- 提供安全的字符串操作，替代 C 风格字符数组。

5. **输入/输出流（I/O Streams）**

- （如 ）（文件操作）（字符串流）。

6. **数值处理**

- `` 定义数值类型的极值，`` 提供数学函数。

------

### **三、其他重要特性**

1. **局部对象析构顺序**

- 局部对象的析构顺序与构造顺序相反（RAII 基础）。

2. **运算符重载**

- 允许自定义运算符行为（如 ）。

3. **友元（friend）**

- 允许非成员函数或类访问私有成员。

4. **静态成员**

- 类的静态成员变量和函数。

#  C++03（ISO/IEC 14882:2003）

C++03（ISO/IEC 14882:2003）是 C++98 的一个**技术修正版本**（Technical Corrigendum），主要修复了标准中的缺陷和模糊表述，**并未引入显著的新特性**。它通常被视为 C++98 的“bug fix”版本，核心特性和语法与 C++98 完全一致。以下是 C++03 的细节说明：

### **一、C++03 的核心变化**

1. **标准文本修正**

- 修复了 C++98 标准中的**语法歧义**和**未定义行为**的表述。

- 例如：模板解析规则、模板友元声明的语法等细节更明确。

2. **标准库的兼容性改进**

- 修正了 STL 中部分容器的接口行为（如  的成员函数异常安全性）。

- 明确  的存储连续性（C++03 保证  是连续内存）。

3. **数值限制的扩展**

- 在 `` 中增加了对  和  的支持（尽管这些类型在 C++11 才正式成为关键字）。

------

### **二、与 C++98 的兼容性**

- **语法完全兼容**：所有 C++98 代码在 C++03 中无需修改即可编译。

- **编译器支持**：主流编译器（如 GCC、MSVC）通常将 C++98 和 C++03 视为同一版本实现。

------

### **三、为什么需要 C++03？**

C++98 标准中存在一些**未明确的边界情况**，例如：

- 模板中嵌套依赖名称的解析规则（需用  消除歧义）。

- 局部模板特化的合法性（C++03 明确禁止）。

这些修正提高了代码的可移植性和一致性。

# **C++11（ISO/IEC 14882:2011）**

C++11（ISO/IEC 14882:2011）是 C++ 的一次重大更新，引入了许多革命性特性，显著提升了代码的简洁性、安全性和性能。以下是 C++11 的核心特性分类总结：

### **一、核心语言特性**

1. **自动类型推导）**

- 编译器自动推断变量类型，简化代码：

```cpp

auto x = 5;          // int

auto str = "hello";  // const char*

```

2. **范围  循环**

- 简化容器遍历：

```cpp

std::vector&lt;int&gt; v = {1, 2, 3};

for (auto&amp; num : v) { std::cout &lt;&lt; num; }

```

3. **右值引用与移动语义）**

- 避免深拷贝，提升性能：

```cpp

std::vector&lt;std::string&gt; v;

v.push_back(std::move(str));  // 移动而非拷贝

```

4. **Lambda 表达式**

- 匿名函数，支持闭包：

```cpp

auto add = [](int a, int b) { return a + b; };

std::sort(v.begin(), v.end(), [](int a, int b) { return a &gt; b; });

```

5. * 关键字**

- 替代```NULL```，明确表示空指针：

```cpp

int* p = nullptr;

```

6. **强类型枚举）**

- 避免命名冲突，限制作用域：

```cpp

enum class Color { Red, Green };

Color c = Color::Red;  // 必须带作用域

```

7. * 常量表达式**

- 编译时计算：

```cpp

constexpr int square(int x) { return x * x; }

int arr[square(3)];  // 编译期确定数组大小

```

8. **委托构造函数**

- 构造函数调用其他构造函数：

```cpp

class A {

public:

A() : A(0) {}      // 委托给 A(int)

A(int x) { /*...*/ }

};

```

9. * 和 **

- 显式标记虚函数重写或禁止继承：

```cpp

class B final {};       // 禁止继承

virtual void foo() override;  // 确保重写基类虚函数

```

------

### **二、标准库增强**

1. **智能指针**

- 自动内存管理：

```cpp

std::unique_ptr&lt;int&gt; ptr(new int(10));  // 独占所有权

std::shared_ptr&lt;int&gt; sptr = std::make_shared&lt;int&gt;(20);  // 共享所有权

```

2. * 多线程支持**

- 原生多线程库：

```cpp

std::thread t([]() { std::cout &lt;&lt; "Hello from thread!"; });

t.join();

```

3. **哈希表容器**

- 新增无序关联容器：

```cpp

std::unordered_map&lt;std::string, int&gt; hash_map;

```

4. * 和 **

- 通用函数包装器：

```cpp

std::function&lt;int(int, int)&gt; func = std::plus&lt;int&gt;();

std::bind(func, 1, std::placeholders::_1)(2);  // 绑定参数

```

5. **正则表达式（``）**

- 支持正则操作：

```cpp

std::regex pattern("\\d+");

bool match = std::regex_search("123", pattern);

```

6. **元组）**

- 多类型值集合：

```cpp

auto t = std::make_tuple(1, "hello", 3.14);

```

------

### **三、其他重要特性**

1. **变长模板（Variadic Templates）**

- 支持任意数量模板参数：

```cpp

template&lt;typename... Args&gt;

void log(Args... args) { /*...*/ }

```

2. **列表初始化（Uniform Initialization）**

- 统一初始化语法：

```cpp

std::vector&lt;int&gt; v{1, 2, 3};  // 替代旧式括号初始化

```

3. * 编译时断言**

- 编译期条件检查：

```cpp

static_assert(sizeof(int) == 4, "int must be 4 bytes");

```

4. * 异常规范**

- 标记函数不抛异常：

```cpp

void foo() noexcept { /*...*/ }

```

# **C++14（ISO/IEC 14882:2014）**

C++14（ISO/IEC 14882:2014）是 C++11 的小幅改进版本，主要目标是完善 C++11 的特性并修复一些缺陷，而非引入重大变革。以下是 C++14 的核心特性分类总结：

### **一、核心语言改进**

1. **泛型 Lambda 表达式**

- Lambda 参数支持```auto```，实现真正的泛型：

```cpp

auto lambda = [](auto x, auto y) { return x + y; };

std::cout &lt;&lt; lambda(1, 2.5);  // 混合类型参数

```

2. * 函数扩展**

- 允函数包含局部变量、循环和简单分支：

```cpp

constexpr int factorial(int n) {

int result = 1;

for (int i = 1; i &lt;= n; ++i) result *= i;

return result;

}

int arr[factorial(5)];  // 编译期计算 120

```

3. **变量模板（Variable Templates）**

- 模板可以定义变量而不仅是类型或函数：

```cpp

template&lt;typename T&gt;

constexpr T pi = T(3.1415926535897932385);

std::cout &lt;&lt; pi&lt;double&gt;;  // 输出 double 精度的 π

```

4. **二进制字面量**

- 直接使用二进制数：

```cpp

int mask = 0b110101;  // 十进制 53

```

5. **数字分隔符（Digit Separators）**

- 提高长数字可读性：

```cpp

int million = 1'000'000;

double pi = 3.141'592'6535;

```

6. **函数返回类型推导 返回类型）**

- 省略尾置返回类型（C++11 需）：

```cpp

auto add(int a, int b) { return a + b; }  // 自动推导为 int

```

7. * 属性**

- 标记过时代码，编译时警告：

```cpp

[[deprecated("Use new_func() instead")]]

void old_func() {}

```

------

### **二、标准库增强**

1. ***

- 补充 C++11 ， 提供工厂函数：

```cpp

auto ptr = std::make_unique&lt;int&gt;(42);  // 替代 new

```

2. **标准库的  支持**

- 部分标准库函数（如  的部分操作）可在编译期使用。

- 方便处理带引号的字符串（如 CSV 文件）：

```cpp

```

------

### **三、其他改进**

1. **聚合成员初始化扩展**

- 允许聚合类（无自定义构造函数的类）使用默认初始化：


2. **Lambda 捕获表达式的改进**

- 支持在捕获列表中直接初始化变量：

```cpp

```

3. * 运算符的扩展**

- 可直接用于成员变量（无需实例化对象）：

# **C++17（ISO/IEC 14882:2020）**

C++17（ISO/IEC 14882:2017）是 C++14 的增量升级版本，虽然没有 C++11 或 C++20 那样的革命性变化，但引入了许多实用特性，进一步简化代码并提升性能。以下是 C++17 的核心特性分类总结：

### **一、核心语言特性**

1. **结构化绑定（Structured Bindings）**

- 解构元组、结构体或数组为独立变量：

```cpp

std::pair&lt;int, std::string&gt; p{42, "hello"};

auto [num, str] = p;  // num=42, str="hello"

```

2. * 和  的初始化语句**

- 在条件语句中定义局部变量：

```cpp

if (auto it = map.find(key); it != map.end()) {

// 使用 it

}  // it 作用域仅限于 if 块

```

3. ***

- 编译期条件分支，简化模板元编程：

```cpp

template &lt;typename T&gt;

auto get_value(T t) {

if constexpr (std::is_pointer_v&lt;T&gt;) return *t;

else return t;

}

```

4. **内联变量（Inline Variables）**

- 允许头文件中定变量，避免多重定义错误：

```cpp

// header.h

inline int global_value = 42;  // 多个 cpp 包含时不会链接错误

```

5. **折叠表达式（Fold Expressions）**

- 简化可变参数模板的展开：

```cpp

template &lt;typename... Args&gt;

auto sum(Args... args) { return (... + args); }  // args1 + args2 + ...

```

6. * 模板参数**

- 非类型模板参数支 ：

```cpp

template &lt;auto value&gt;

void print() { std::cout &lt;&lt; value; }

print&lt;42&gt;();  // 输出 42

```

7. ***

- 明确表示字节的类型（替）：

```cpp

std::byte b{0xFF};

```

8. **构造函数模板推导（CTAD）**

- 省略模板参数，自动推导容器类型：

```cpp

std::pair p(1, "hello");  // 自动推导为 std::pair&lt;int, const char*&gt;

std::vector v{1, 2, 3};   // 推导为 std::vector&lt;int&gt;

```

------

### **二、标准库增强**

1. ***

- 标准库算法支持并行执行：

7. * 和 **

- 统一调用函数和展开元组参数：

### **三、其他改进**

1. **嵌套命名空间定义简化**

# C++20（ISO/IEC 14882:2020）**

C++20（ISO/IEC 14882:2020）是继 C++17 之后的重大更新，引入了许多革命性特性，显著提升了代码的表达能力、性能和安全性。以下是 C++20 的核心特性分类总结：

### **一、核心语言特性**

1. **概念（Concepts）**

- 对模板参数进行约束，提升错误信息可读性：

```cpp

template &lt;typename T&gt;

concept Addable = requires(T a, T b) { a + b; };  // 要求类型支持 + 操作


template &lt;Addable T&gt;

T sum(T a, T b) { return a + b; }  // 仅接受满足 Addable 的类型

```

2. **模块（Modules）**

- 替代头文件），加快编译速度：

```cpp

// math.ixx (模块接口文件)

export module math;

export int add(int a, int b) { return a + b; }


// main.cpp

import math;

int main() { return add(1, 2); }

```

3. **协程（Coroutines）**

- 支持挂起/恢复的函数，简化异步代码：

```cpp

generator&lt;int&gt; range(int start, int end) {

for (int i = start; i &lt; end; ++i)

co_yield i;  // 挂起并返回值

}

for (int i : range(1, 5)) { /*...*/ }  // 输出 1, 2, 3, 4

```

4. **三路比较，Spaceship Operator）**

- 简化比较运算符定义：

```cpp

struct Point {

int x, y;

auto operator&lt;=&gt;(const Point&amp;) const = default;  // 自动生成 ==, !=, &lt;, &gt; 等

};

```

5. **范围  循环的初始化语句**

- 允许在范 中定义局部变量：

```cpp

for (auto vec = get_vector(); auto&amp; x : vec) { /*...*/ }

```

6. * 进一步扩展**

- 支函数、动态内存分配等：

```cpp

constexpr int safe_divide(int a, int b) {

if (b == 0) throw "Division by zero";  // 编译期异常

return a / b;

}

```

7. * 立即函数**

- 强制函数在编译期执行：

```cpp

consteval int square(int x) { return x * x; }

int arr[square(3)];  // 必须编译期计算

```

8. * 属性**

- 优化空类型成员的内存占用：

```cpp

struct Empty {};

struct S {

[[no_unique_address]] Empty e;  // 可能不占额外内存

int x;

};

```

### **二、标准库增强**

1. **范围库（Ranges）**

4. ***

- 自动合并（join）的线程，避免资源泄漏：

6. **日历和时区支持（`` 扩展）**

- 处理日期和时间：


### **三、其他重要特性**

2. **位操作库（``）**

# **C++23（ISO/IEC 14882:2023）**

C++23（ISO/IEC 14882:2023）是 C++20 之后的增量更新版本，虽然不如 C++20 那样引入大量革命性特性，但仍包含许多实用改进，进一步简化代码、增强表达能力和性能。以下是 C++23 的核心特性分类总结：

### **一、核心语言特性**

1. * 和 **

- 简化条件编译的语法，风格一致：

```cpp

#ifdef FEATURE_A

// ...

#elifdef FEATURE_B  // 替代 #elif defined(FEATURE_B)

// ...

#endif

```

2. * 和 （显式复制构造）**

- 强制复制对象并保留类型推导：

```cpp

auto v2 = auto(v1);  // 显式复制，v2 是 std::vector&lt;int&gt;

```

3. **多维  支持）**

- 允许自定义多维下标运算符：

```cpp

struct Matrix {

int data[3][3];

int* operator[](size_t i) { return data[i]; }

int operator[](size_t i, size_t j) const { return data[i][j]; }  // C++23

};

Matrix m;

m[1, 2] = 42;  // 多维访问

```

4. * 扩展**

- 支函数中 （编译期动态内存管理）：

```cpp

constexpr auto create() {

auto p = std::make_unique&lt;int&gt;(42);

return *p;

}

```

5. ***

- 检测当前是否在编译期上下文中执行：

```cpp
}

```

6. * 属性的位置放宽**

- 允许属性出现在更多位置（捕获列表前）：


### **二、标准库增强**

# C++六大默认成员函数

在 C++ 中，如果一个类没有显式定义某些特殊成员函数，编译器会自动生成默认版本。这些默认函数共有 **6 个**，通常被称为 **"六大默认成员函数"**（或 "六大特殊成员函数"）。以下是它们的详细说明：

```c++

class Example {

public:

Example() = default;                 // 显式要求生成默认构造

~Example() = default;                // 显式生成默认析构

Example(const Example&amp;) = delete;    // 禁用拷贝构造

Example&amp; operator=(Example&amp;&amp;) = default; // 显式生成移动赋值

ClassName&amp; operator=(ClassName&amp;&amp;);

};

```

### 1. **默认构造函数** )

- **形式**:

- **作用**: 初始化对象的成员（基本类型不初始化，类类型调用其默认构造）。

- **生成条件**: 当类中**没有定义任何构造函数**时生成。

- **注意**: 如果定义了其他构造函数，则不会生成默认构造，需手动添加。

------

### 2. **默认析构函数** )

- **形式**:

- **作用**: 释放对象资源（成员变量会自动析构）。

- **生成条件**: 总是生成，除非显式定义。

- **注意**: 若类管理动态资源（如指针），通常需要手动定义析构函数。

------

### 3. **默认拷贝构造函数** )

- **形式**:

- **作用**: 用同类型的另一个对象初始化新对象（浅拷贝）。

- **生成条件**: 当类中**未显式定义拷贝构造**时生成。

- **注意**: 若类包含指针或动态资源，需手动实现深拷贝。

------

### 4. **默认拷贝赋值运算符** )

- **形式**:

- **作用**: 将一个对象的值赋给另一个已存在的对象（浅拷贝）。

- **生成条件**: 当类中**未显式定义拷贝赋值**时生成。

- **注意**: 类似拷贝构造，需处理深拷贝问题。

------

### 5. **默认移动构造函数** ) (C++11 引入)

- **形式**:

- **作用**: 通过“窃取”右值对象的资源来初始化新对象。

- **生成条件**: 当类中**未显式定义移动构造、拷贝构造、拷贝赋值、析构函数**时生成。

- **注意**: 适用于优化临时对象的资源转移。

------

### 6. **默认移动赋值运算符** ) (C++11 引入)

- **形式**:

- **作用**: 通过“窃取”右值对象的资源赋值给已存在对象。

- **生成条件**: 当类中**未显式定义移动赋值、拷贝构造、拷贝赋值、析构函数**时生成。

------

### 总结表

| 默认函数               | 形式                          | 生成条件（未显式定义时）        |

| ---------------------- | ----------------------------- | ------------------------------- |

| 默认构造函数           |                  | 无任何构造函数                  |

| 析构函数               |                 | 总是生成                        |

| 拷贝构造函数           |  | 无拷贝构造                      |

| 拷贝赋值运算符         |    | 无拷贝赋值                      |

| 移动构造函数 (C++11)   |       | 无拷贝/移动构造、拷贝赋值、析构 |

| 移动赋值运算符 (C++11) |    | 无拷贝/移动赋值、拷贝构造、析构 |

------

### 关键注意事项

1. **浅拷贝问题**：默认拷贝构造和拷贝赋值是浅拷贝，可能引发双重释放（需手动实现深拷贝）。

2. **Rule of Three/Five/Zero**：

- 如果定义了拷贝构造、拷贝赋值或析构中的任意一个，通常需要定义全部（C++03）。

- 在 C++11 后，还需考虑移动构造和移动赋值（Rule of Five）。

- 最佳实践是使用  或  明确需求，或遵循 Rule of Zero（依赖智能指针等自动管理资源）。

3. * 和 **：

- 可用  显式要求编译器生成默认实现。

- 用  禁止特定函数（如禁用拷贝）。
