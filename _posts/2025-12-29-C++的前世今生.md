<p style="">#**C++98（ISO/IEC 14882:1998）**</p><p style="">C++98 是 C++ 的第一个标准化版本（ISO/IEC 14882:1998），它正式确立了 C++ 的核心语言特性和标准库。以下是 C++98 的主要特性总结：</p><p style="">### 一、核心语言特性**</p><p style="">1. **模板（Templates）**</p><p style="">   - 支持函数模板和类模板，实现泛型编程。</p><p style="">   - 例如<code>std::vectorstd::sort</code> 等标准库组件依赖模板。</p><p style="">2. **标准模板库（STL）**</p><p style="">   - 包含容器（如 <code>vectorlistmap</code>）、迭代器（iterators）和算法（如 <code>sortfind</code>）。</p><p style="">   - 基于泛型编程思想，强调“数据与算法分离”。</p><p style="">3. **异常处理（Exception Handling）**</p><p style="">   - 引入 <code>trycatchthrow</code> 机制，支持错误处理的标准化。</p><p style="">4. **命名空间（Namespaces）**</p><p style="">   - 避免命名冲突，例如 <code>std</code> 是标准库的命名空间。</p><p style="">5. **RTTI（运行时类型识别）**</p><p style="">   - 支持 <code>typeid</code> 和 <code>dynamic_cast</code>，允许在运行时检查类型。</p><p style="">6. **bool 类型**</p><p style="">   - 引入 <code>bool</code> 关键字<code>truefalse</code>），取代传统的 <code>int</code> 表示布尔值。</p><p style="">7. **mutable 关键字**</p><p style="">   - 允许在 <code>const</code> 成员函数中修改被标记为 <code>mutable</code> 的成员变量。</p><p style="">8. **显式类型转换**</p><p style="">   - 提供 <code>static_castdynamic_castconst_castreinterpret_cast</code>，替代 C 风格的强制转换。</p><p style="">9. **默认参数和函数重载**</p><p style="">   - 支持函数参数的默认值和函数重载（相同函数名，不同参数列表）。</p><p style="">------</p><p style="">### **二、标准库组件**</p><p style="">1. **容器（Containers）**</p><p style="">   - 序列容器<code>vectordequelist</code></p><p style="">   - 关联容器<code>setmapmultisetmultimap</code></p><p style="">   - 适配器<code>stackqueuepriority_queue</code></p><p style="">2. **迭代器（Iterators）**</p><p style="">   - 提供统一的遍历容器元素的接口（如 <code>begin()end()</code>）。</p><p style="">3. **算法（Algorithms）**</p><p style="">   - 如 <code>sort()find()copy()</code> 等，通过迭代器操作容器。</p><p style="">4. **字符串类（std::string）**</p><p style="">   - 提供安全的字符串操作，替代 C 风格字符数组。</p><p style="">5. **输入/输出流（I/O Streams）**</p><p style="">   - <code>iostream</code>（如 <code>cincout</code>）<code>fstream</code>（文件操作）<code>sstream</code>（字符串流）。</p><p style="">6. **数值处理**</p><p style="">   - `` 定义数值类型的极值，`` 提供数学函数。</p><p style="">------</p><p style="">### **三、其他重要特性**</p><p style="">1. **局部对象析构顺序**</p><p style="">   - 局部对象的析构顺序与构造顺序相反（RAII 基础）。</p><p style="">2. **运算符重载**</p><p style="">   - 允许自定义运算符行为（如 <code>+&lt;&lt;</code>）。</p><p style="">3. **友元（friend）**</p><p style="">   - 允许非成员函数或类访问私有成员。</p><p style="">4. **静态成员**</p><p style="">   - 类的静态成员变量和函数。</p><p style="">#  C++03（ISO/IEC 14882:2003）</p><p style="">C++03（ISO/IEC 14882:2003）是 C++98 的一个**技术修正版本**（Technical Corrigendum），主要修复了标准中的缺陷和模糊表述，**并未引入显著的新特性**。它通常被视为 C++98 的“bug fix”版本，核心特性和语法与 C++98 完全一致。以下是 C++03 的细节说明：</p><p style="">### **一、C++03 的核心变化**</p><p style="">1. **标准文本修正**</p><p style="">   - 修复了 C++98 标准中的**语法歧义**和**未定义行为**的表述。</p><p style="">   - 例如：模板解析规则、模板友元声明的语法等细节更明确。</p><p style="">2. **标准库的兼容性改进**</p><p style="">   - 修正了 STL 中部分容器的接口行为（如 <code>std::vector</code> 的成员函数异常安全性）。</p><p style="">   - 明确 <code>std::basic_string</code> 的存储连续性（C++03 保证 <code>&amp;s[0]</code> 是连续内存）。</p><p style="">3. **数值限制的扩展**</p><p style="">   - 在 `` 中增加了对 <code>long long</code> 和 <code>unsigned long long</code> 的支持（尽管这些类型在 C++11 才正式成为关键字）。</p><p style="">------</p><p style="">### **二、与 C++98 的兼容性**</p><p style="">- **语法完全兼容**：所有 C++98 代码在 C++03 中无需修改即可编译。</p><p style="">- **编译器支持**：主流编译器（如 GCC、MSVC）通常将 C++98 和 C++03 视为同一版本实现。</p><p style="">------</p><p style="">### **三、为什么需要 C++03？**</p><p style="">C++98 标准中存在一些**未明确的边界情况**，例如：</p><p style="">- 模板中嵌套依赖名称的解析规则（需用 <code>typename</code> 消除歧义）。</p><p style="">- 局部模板特化的合法性（C++03 明确禁止）。</p><p style="">  这些修正提高了代码的可移植性和一致性。</p><p style=""># **C++11（ISO/IEC 14882:2011）**</p><p style="">C++11（ISO/IEC 14882:2011）是 C++ 的一次重大更新，引入了许多革命性特性，显著提升了代码的简洁性、安全性和性能。以下是 C++11 的核心特性分类总结：</p><p style="">### **一、核心语言特性**</p><p style="">1. **自动类型推导<code>auto</code>）**</p><p style="">   - 编译器自动推断变量类型，简化代码：</p><p style="">     ```cpp</p><p style="">     auto x = 5;          // int</p><p style="">     auto str = "hello";  // const char*</p><p style="">     ```</p><p style="">2. **范围 <code>for</code> 循环**</p><p style="">   - 简化容器遍历：</p><p style="">     ```cpp</p><p style="">     std::vector&lt;int&gt; v = {1, 2, 3};</p><p style="">     for (auto&amp; num : v) { std::cout &lt;&lt; num; }</p><p style="">     ```</p><p style="">3. **右值引用与移动语义<code>&amp;&amp;</code>）**</p><p style="">   - 避免深拷贝，提升性能：</p><p style="">     ```cpp</p><p style="">     std::vector&lt;std::string&gt; v;</p><p style="">     v.push_back(std::move(str));  // 移动而非拷贝</p><p style="">     ```</p><p style="">4. **Lambda 表达式**</p><p style="">   - 匿名函数，支持闭包：</p><p style="">     ```cpp</p><p style="">     auto add = [](int a, int b) { return a + b; };</p><p style="">     std::sort(v.begin(), v.end(), [](int a, int b) { return a &gt; b; });</p><p style="">     ```</p><p style="">5. *<code>nullptr</code> 关键字**</p><p style="">   - 替代```NULL```，明确表示空指针：</p><p style="">     ```cpp</p><p style="">     int* p = nullptr;</p><p style="">     ```</p><p style="">6. **强类型枚举<code>enum class</code>）**</p><p style="">   - 避免命名冲突，限制作用域：</p><p style="">     ```cpp</p><p style="">     enum class Color { Red, Green };</p><p style="">     Color c = Color::Red;  // 必须带作用域</p><p style="">     ```</p><p style="">7. *<code>constexpr</code> 常量表达式**</p><p style="">   - 编译时计算：</p><p style="">     ```cpp</p><p style="">     constexpr int square(int x) { return x * x; }</p><p style="">     int arr[square(3)];  // 编译期确定数组大小</p><p style="">     ```</p><p style="">8. **委托构造函数**</p><p style="">   - 构造函数调用其他构造函数：</p><p style="">     ```cpp</p><p style="">     class A {</p><p style="">     public:</p><p style="">         A() : A(0) {}      // 委托给 A(int)</p><p style="">         A(int x) { /*...*/ }</p><p style="">     };</p><p style="">     ```</p><p style="">9. *<code>override</code> 和 <code>final</code>**</p><p style="">   - 显式标记虚函数重写或禁止继承：</p><p style="">     ```cpp</p><p style="">     class B final {};       // 禁止继承</p><p style="">     virtual void foo() override;  // 确保重写基类虚函数</p><p style="">     ```</p><p style="">------</p><p style="">### **二、标准库增强**</p><p style="">1. **智能指针**</p><p style="">   - 自动内存管理：</p><p style="">     ```cpp</p><p style="">     std::unique_ptr&lt;int&gt; ptr(new int(10));  // 独占所有权</p><p style="">     std::shared_ptr&lt;int&gt; sptr = std::make_shared&lt;int&gt;(20);  // 共享所有权</p><p style="">     ```</p><p style="">2. *<code>std::thread</code> 多线程支持**</p><p style="">   - 原生多线程库：</p><p style="">     ```cpp</p><p style="">     std::thread t([]() { std::cout &lt;&lt; "Hello from thread!"; });</p><p style="">     t.join();</p><p style="">     ```</p><p style="">3. **哈希表容器**</p><p style="">   - 新增无序关联容器：</p><p style="">     ```cpp</p><p style="">     std::unordered_map&lt;std::string, int&gt; hash_map;</p><p style="">     ```</p><p style="">4. *<code>std::function</code> 和 <code>std::bind</code>**</p><p style="">   - 通用函数包装器：</p><p style="">     ```cpp</p><p style="">     std::function&lt;int(int, int)&gt; func = std::plus&lt;int&gt;();</p><p style="">     std::bind(func, 1, std::placeholders::_1)(2);  // 绑定参数</p><p style="">     ```</p><p style="">5. **正则表达式（``）**</p><p style="">   - 支持正则操作：</p><p style="">     ```cpp</p><p style="">     std::regex pattern("\\d+");</p><p style="">     bool match = std::regex_search("123", pattern);</p><p style="">     ```</p><p style="">6. **元组<code>std::tuple</code>）**</p><p style="">   - 多类型值集合：</p><p style="">     ```cpp</p><p style="">     auto t = std::make_tuple(1, "hello", 3.14);</p><p style="">     ```</p><p style="">------</p><p style="">### **三、其他重要特性**</p><p style="">1. **变长模板（Variadic Templates）**</p><p style="">   - 支持任意数量模板参数：</p><p style="">     ```cpp</p><p style="">     template&lt;typename... Args&gt;</p><p style="">     void log(Args... args) { /*...*/ }</p><p style="">     ```</p><p style="">2. **列表初始化（Uniform Initialization）**</p><p style="">   - 统一初始化语法：</p><p style="">     ```cpp</p><p style="">     std::vector&lt;int&gt; v{1, 2, 3};  // 替代旧式括号初始化</p><p style="">     ```</p><p style="">3. *<code>static_assert</code> 编译时断言**</p><p style="">   - 编译期条件检查：</p><p style="">     ```cpp</p><p style="">     static_assert(sizeof(int) == 4, "int must be 4 bytes");</p><p style="">     ```</p><p style="">4. *<code>noexcept</code> 异常规范**</p><p style="">   - 标记函数不抛异常：</p><p style="">     ```cpp</p><p style="">     void foo() noexcept { /*...*/ }</p><p style="">     ```</p><p style=""># **C++14（ISO/IEC 14882:2014）**</p><p style="">C++14（ISO/IEC 14882:2014）是 C++11 的小幅改进版本，主要目标是完善 C++11 的特性并修复一些缺陷，而非引入重大变革。以下是 C++14 的核心特性分类总结：</p><p style="">### **一、核心语言改进**</p><p style="">1. **泛型 Lambda 表达式**</p><p style="">   - Lambda 参数支持```auto```，实现真正的泛型：</p><p style="">     ```cpp</p><p style="">     auto lambda = [](auto x, auto y) { return x + y; };</p><p style="">     std::cout &lt;&lt; lambda(1, 2.5);  // 混合类型参数</p><p style="">     ```</p><p style="">2. *<code>constexpr</code> 函数扩展**</p><p style="">   - 允<code>constexpr</code>函数包含局部变量、循环和简单分支：</p><p style="">     ```cpp</p><p style="">     constexpr int factorial(int n) {</p><p style="">         int result = 1;</p><p style="">         for (int i = 1;  // 替代 new</p><p style="">     ```</p><p style="">2. **标准库的 <code>constexpr</code> 支持**</p><p style="">   - 部分标准库函数（如 <code>std::arraystd::tuple</code> 的部分操作）可在编译期使用。</p><p style="">3. *<code>std::integer_sequence</code>**</p><p style="">   - 编译时整数序列，用于元编程：</p><p style="">     ```cpp</p><p style="">     template&lt;typename T, T...  // 输出: 1 2 3</p><p style="">     ```</p><p style="">4. *<code>std::exchange</code>**</p><p style="">   - 原子性地替换对象值并返回旧值：</p><p style="">     ```cpp</p><p style="">     int x = 1;</p><p style="">     int old = std::exchange(x, 42);  // x=42, old=1</p><p style="">     ```</p><p style="">5. *<code>std::quoted</code>**</p><p style="">   - 方便处理带引号的字符串（如 CSV 文件）：</p><p style="">     ```cpp</p><p style="">     std::cout &lt;&lt; std::quoted("Hello");  // 输出: "Hello"</p><p style="">     ```</p><p style="">------</p><p style="">### **三、其他改进**</p><p style="">1. **聚合成员初始化扩展**</p><p style="">   - 允许聚合类（无自定义构造函数的类）使用默认初始化：</p><p style="">     ```cpp</p><p style="">     struct Point { int x; int y; };</p><p style="">     Point p{1};  // y 初始化为 0（C++11 需完整初始化）</p><p style="">     ```</p><p style="">2. **Lambda 捕获表达式的改进**</p><p style="">   - 支持在捕获列表中直接初始化变量：</p><p style="">     ```cpp</p><p style="">     auto lambda = [value = 42]() { return value; };</p><p style="">     ```</p><p style="">3. *<code>sizeof</code> 运算符的扩展**</p><p style="">   - 可直接用于成员变量（无需实例化对象）：</p><p style="">     ```cpp</p><p style="">     struct S { int x; double y; };</p><p style="">     size_t sz = sizeof(S::x);  // 等价于 sizeof(int)</p><p style="">     ```</p><p style=""># **C++17（ISO/IEC 14882:2020）**</p><p style="">C++17（ISO/IEC 14882:2017）是 C++14 的增量升级版本，虽然没有 C++11 或 C++20 那样的革命性变化，但引入了许多实用特性，进一步简化代码并提升性能。以下是 C++17 的核心特性分类总结：</p><p style="">### **一、核心语言特性**</p><p style="">1. **结构化绑定（Structured Bindings）**</p><p style="">   - 解构元组、结构体或数组为独立变量：</p><p style="">     ```cpp</p><p style="">     std::pair&lt;int, std::string&gt; p{42, "hello"};</p><p style="">     auto [num, str] = p;  // num=42, str="hello"</p><p style="">     ```</p><p style="">2. *<code>if</code> 和 <code>switch</code> 的初始化语句**</p><p style="">   - 在条件语句中定义局部变量：</p><p style="">     ```cpp</p><p style="">     if (auto it = map.find(key); it != map.end()) {</p><p style="">         // 使用 it</p><p style="">     }  // it 作用域仅限于 if 块</p><p style="">     ```</p><p style="">3. *<code>constexpr if</code>**</p><p style="">   - 编译期条件分支，简化模板元编程：</p><p style="">     ```cpp</p><p style="">     template &lt;typename T&gt;</p><p style="">     auto get_value(T t) {</p><p style="">         if constexpr (std::is_pointer_v&lt;T&gt;) return *t;</p><p style="">         else return t;</p><p style="">     }</p><p style="">     ```</p><p style="">4. **内联变量（Inline Variables）**</p><p style="">   - 允许头文件中定<code>inline</code>变量，避免多重定义错误：</p><p style="">     ```cpp</p><p style="">     // header.h</p><p style="">     inline int global_value = 42;  // 多个 cpp 包含时不会链接错误</p><p style="">     ```</p><p style="">5. **折叠表达式（Fold Expressions）**</p><p style="">   - 简化可变参数模板的展开：</p><p style="">     ```cpp</p><p style="">     template &lt;typename... value; }</p><p style="">     print&lt;42&gt;();  // 输出 42</p><p style="">     ```</p><p style="">7. *<code>std::byte</code>**</p><p style="">   - 明确表示字节的类型（替<code>charunsigned char</code>）：</p><p style="">     ```cpp</p><p style="">     std::byte b{0xFF};</p><p style="">     ```</p><p style="">8. **构造函数模板推导（CTAD）**</p><p style="">   - 省略模板参数，自动推导容器类型：</p><p style="">     ```cpp</p><p style="">     std::pair p(1, "hello");  // 自动推导为 std::pair&lt;int, const char*&gt;</p><p style="">     std::vector v{1, 2, 3};   // 推导为 std::vector&lt;int&gt;</p><p style="">     ```</p><p style="">------</p><p style="">### **二、标准库增强**</p><p style="">1. *<code>std::optional</code>**</p><p style="">   - 表示可选值，避免使<code>nullptr</code>或特殊值：</p><p style="">     ```cpp</p><p style="">     std::optional&lt;int&gt; operator=(ClassName&amp;&amp;)</code></p><p style="">- **作用**: 通过“窃取”右值对象的资源赋值给已存在对象。</p><p style="">- **生成条件**: 当类中**未显式定义移动赋值、拷贝构造、拷贝赋值、析构函数**时生成。</p><p style="">------</p><p style="">### 总结表</p><p style="">| 默认函数               | 形式                          | 生成条件（未显式定义时）        |</p><p style="">| ---------------------- | ----------------------------- | ------------------------------- |</p><p style="">| 默认构造函数           | <code>ClassName()</code>                 | 无任何构造函数                  |</p><p style="">| 析构函数               | <code>~ClassName()</code>                | 总是生成                        |</p><p style="">| 拷贝构造函数           | <code>ClassName(const ClassName&amp;)</code> | 无拷贝构造                      |</p><p style="">| 拷贝赋值运算符         | <code>ClassName&amp; operator=(...)</code>   | 无拷贝赋值                      |</p><p style="">| 移动构造函数 (C++11)   | <code>ClassName(ClassName&amp;&amp;)</code>      | 无拷贝/移动构造、拷贝赋值、析构 |</p><p style="">| 移动赋值运算符 (C++11) | <code>ClassName&amp; operator=(...)</code>   | 无拷贝/移动赋值、拷贝构造、析构 |</p><p style="">------</p><p style="">### 关键注意事项</p><p style="">1. **浅拷贝问题**：默认拷贝构造和拷贝赋值是浅拷贝，可能引发双重释放（需手动实现深拷贝）。</p><p style="">2. **Rule of Three/Five/Zero**：</p><p style="">   - 如果定义了拷贝构造、拷贝赋值或析构中的任意一个，通常需要定义全部（C++03）。</p><p style="">   - 在 C++11 后，还需考虑移动构造和移动赋值（Rule of Five）。</p><p style="">   - 最佳实践是使用 <code>=default</code> 或 <code>=delete</code> 明确需求，或遵循 Rule of Zero（依赖智能指针等自动管理资源）。</p><p style="">3. *<code>=default</code> 和 <code>=delete</code>**：</p><p style="">   - 可用 <code>=default</code> 显式要求编译器生成默认实现。</p><p style="">   - 用 <code>=delete</code> 禁止特定函数（如禁用拷贝）。</p>
