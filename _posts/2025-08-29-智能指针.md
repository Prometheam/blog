<p style="">C++ 智能指针是管理动态分配内存的强大工具，旨在自动释放对象，有效防止内存泄漏，并简化资源管理。它们是标准库（&lt;memory&gt; 头文件）的一部分，核心思想是将内存所有权封装在对象中，利用析构函数自动释放内存。</p><h2 style="" id="1.-std%3A%3Aunique_ptr-(c%2B%2B11)">1. std::unique_ptr (C++11)</h2><p style="">	- 核心概念：独占所有权。同一时间只有一个 unique_ptr 拥有并负责管理所指对象。</p><p style="">	- 特性：</p><p style="">		- 不可复制 (unique_ptr 的拷贝构造函数和拷贝赋值运算符被删除)。</p><p style="">		- 可移动（通过 std::move），所有权随之转移。</p><p style="">		- 轻量级，几乎无额外开销（通常与裸指针大小相同）。</p><p style="">		- 支持自定义删除器（用于管理非内存资源，如文件句柄、套接字）。</p><p style="">	- 使用场景：</p><p style="">		- 管理单个动态分配对象或数组（std::unique_ptr&lt;T[]&gt;）</p><p style="">		- 工厂函数返回资源。</p><p style="">		- 作为类的成员变量，表示独占拥有的资源。</p><p style="">		- 在容器中存储指向多态对象的指针。</p><h2 style="" id="2.-std%3A%3Ashared_ptr-(c%2B%2B11)">2. std::shared_ptr (C++11)</h2><p style="">	-核心概念：共享所有权。多个 shared_ptr 可以同时拥有并管理同一个对象。对象在所有最后一个指向它的 shared_ptr 被销毁（或重置）时才被销毁。</p><p style="">	- 实现机制：使用引用计数。每个被管理的对象都有一个关联的控制块（通常动态分配），其中包含：</p><p style="">		- 指向被管理对象的指针。</p><p style="">		- 强引用计数（shared_ptr 的数量）。</p><p style="">		- 弱引用计数（weak_ptr 的数量，见下文）。</p><p style="">		- 自定义删除器（如果提供）。</p><p style="">		- 自定义分配器（如果提供） </p><p style="">	- 特性：</p><p style="">		- 可复制（增加引用计数）。</p><p style="">		- 可移动（所有权转移，不增加也不减少引用计数）。</p><p style="">		- 有额外开销（控制块大小通常为两个指针）。</p><p style="">		- 支持自定义删除器和分配器。</p><p style="">		- 线程安全：引用计数的增减是原子的，但访问所指对象本身仍需外部同步。</p><p style="">	- 使用场景：</p><p style="">		- 多个实体需要共享访问同一对象，且无法明确谁应该最后释放对象时。</p><p style="">		- 缓存。</p><p style="">		- 监听器/观察者列表。</p><p style="">		- 复杂的数据结构（如图、树节点）。</p><h2 style="" id="3.-std%3A%3Aweak_ptr-(c%2B%2B11)">3. std::weak_ptr (C++11)</h2><p style="">	- 核心概念：弱引用。weak_ptr 指向一个由 shared_ptr 管理的对象，但不拥有该对象，不影响其引用计数。</p><p style="">	- 目的：解决 shared_ptr 循环引用问题（两个或多个对象通过 shared_ptr 互相持有，导致引用计数永不归零，内存泄漏）。weak_ptr 用于打破循环。</p><p style="">	- 特性：</p><p style="">		- 必须从 shared_ptr 或另一个 weak_ptr 构造/赋值。</p><p style="">		- 不能直接访问所指对象（没有 operator* 或 operator-&gt;）。</p><p style="">		- 需要使用 lock() 成员函数尝试获取一个临时的 shared_ptr 来安全访问对象。如果底层对象已被销毁，lock() 返回一个空的 shared_ptr。</p><p style="">		- 可用来检查资源是否依然存在 (expired() 成员函数)。</p><p style="">	- 使用场景：</p><p style="">		- 打破 shared_ptr 的循环引用（例如，父对象持有子对象的 shared_ptr，子对象持有指向父对象的 weak_ptr）。</p><p style="">		- 缓存：持有对可能已过期资源的弱引用，需要时尝试重新加载。</p><p style="">		- 观察者模式：观察者持有对主题的弱引用，避免主题被观察者意外保持存活。</p><h2 style="" id="4.-std%3A%3Aauto_ptr-(c%2B%2B98%2F03%2C-%E5%B7%B2%E5%BA%9F%E5%BC%83%E4%BA%8E-c%2B%2B11%2C-%E7%A7%BB%E9%99%A4%E4%BA%8E-c%2B%2B17)">4. std::auto_ptr (C++98/03, 已废弃于 C++11, 移除于 C++17)</h2><p style="">	- 曾经目的：提供基本的独占所有权语义。</p><p style="">	- 严重缺陷：</p><p style="">		- 尝试复制时执行移动语义（所有权转移），留下源指针为 nullptr。这极其违反直觉且容易导致悬空指针和崩溃。</p><p style="">		- 不能在标准容器（如 std::vector）中安全使用。</p><p style="">	- <strong>绝对不要在新代码中使用！用 std::unique_ptr 替代。</strong></p><h2 style="" id="5%E3%80%81%E8%A1%A5%E5%85%85%E4%BA%8B%E5%AE%9C">5、补充事宜</h2><p style="">1. std::unique_ptr 成员函数</p><p style="">		reset()	释放当前对象并接管新对象（或置空）	ptr.reset(new T);</p><p style="">		release()	放弃所有权，返回原始指针并将自身置空	T* raw = ptr.release();</p><p style="">		get()	返回指向被管理对象的原始指针（不放弃所有权）	T* raw = ptr.get();</p><p style="">		swap()	交换两个 unique_ptr 的内容	ptr1.swap(ptr2);</p><p style="">		operator bool	检查是否持有对象（非空）	if (ptr) { ... }</p><p style="">		operator-&gt;	访问被管理对象的成员	ptr-&gt;doSomething();</p><p style="">		operator*	解引用被管理对象	*ptr = value;</p><p style="">		operator[]	仅用于数组特化版（unique_ptr&lt;T[]&gt;），访问数组元素	ptr[0] = 42;</p><p style="">2. std::shared_ptr 成员函数</p><p style="">		reset()	释放当前对象并接管新对象（或置空），减少原引用计数	ptr.reset(new T);</p><p style="">		get()	返回指向被管理对象的原始指针（不放弃所有权）	T* raw = ptr.get();</p><p style="">		swap()	交换两个 shared_ptr 的内容	ptr1.swap(ptr2);</p><p style="">		use_count()	返回强引用计数（线程安全但仅限调试）	long count = ptr.use_count();</p><p style="">		unique()	检查是否独占对象（C++20 已弃用，用 use_count() == 1 替代）	if (ptr.unique()) { ... }</p><p style="">		operator bool	检查是否持有对象（非空）	if (ptr) { ... }</p><p style="">		operator-&gt;	访问被管理对象的成员	ptr-&gt;doSomething();</p><p style="">		operator*	解引用被管理对象	*ptr = value;</p><p style="">		operator[]	(C++17+) 用于数组特化版（shared_ptr&lt;T[]&gt;），访问数组元素	ptr[0] = 42;</p><p style="">3. std::weak_ptr 成员函数</p><p style="">		lock()	核心函数：尝试提升为 shared_ptr，失败返回空	auto sp = wp.lock();</p><p style="">		reset()	释放当前弱引用，置为空指针	wp.reset();</p><p style="">		swap()	交换两个 weak_ptr 的内容	wp1.swap(wp2);</p><p style="">		use_count()	返回关联的 shared_ptr 的强引用计数	long count = wp.use_count();</p><p style="">		expired()	检查关联对象是否已被销毁（等价于 use_count() == 0）	if (wp.expired()) { ... }</p><p style="">		operator bool	检查是否关联对象（即使对象已销毁）	if (wp) { ... } (不常用)</p><p style="">4.std::unique_ptr 的自定义删除器</p><pre><code>//定义，基本语法
std::unique_ptr&lt;T, Deleter&gt; ptr(raw_ptr, deleter);</code></pre><ul><li><p style=""><code>T</code>：指针指向的类型</p></li><li><p style=""><code>Deleter</code>：删除器的类型</p></li><li><p style=""><code>raw_ptr</code>：原始指针</p></li><li><p style=""><code>deleter</code>：删除器实例</p></li></ul><p style="">使用示例</p><p style="">示例 1：函数指针作为删除器</p><pre><code>#include &lt;iostream&gt;
#include &lt;memory&gt;
#include &lt;cstdio&gt;

void file_deleter(FILE* file) {
    if (file) {
        std::cout &lt;&lt; "Closing file\n";
        fclose(file);
    }
}

int main() {
    // 使用函数指针作为删除器
    std::unique_ptr&lt;FILE, decltype(&amp;file_deleter)&gt; file(
        fopen("test.txt", "w"), 
        file_deleter
    );
    
    if (file) {
        fputs("Hello, World!", file.get());
    }
    
    // 文件会在 unique_ptr 析构时自动关闭
    return 0;
}</code></pre><p style="">示例 2：Lambda 表达式作为删除器</p><pre><code>#include &lt;iostream&gt;
#include &lt;memory&gt;
#include &lt;cstdio&gt;

int main() {
    // 使用 Lambda 作为删除器
    auto file_deleter = [](FILE* file) {
        if (file) {
            std::cout &lt;&lt; "Closing file via lambda\n";
            fclose(file);
        }
    };
    
    std::unique_ptr&lt;FILE, decltype(file_deleter)&gt; file(
        fopen("test.txt", "w"), 
        file_deleter
    );
    
    if (file) {
        fputs("Hello, World!", file.get());
    }
    
    return 0;
}</code></pre><p style="">示例 3：函数对象作为删除器</p><pre><code>#include &lt;iostream&gt;
#include &lt;memory&gt;
#include &lt;cstdio&gt;

struct FileDeleter {
    void operator()(FILE* file) const {
        if (file) {
            std::cout &lt;&lt; "Closing file via functor\n";
            fclose(file);
        }
    }
};

int main() {
    // 使用函数对象作为删除器
    std::unique_ptr&lt;FILE, FileDeleter&gt; file(fopen("test.txt", "w"));
    
    if (file) {
        fputs("Hello, World!", file.get());
    }
    
    return 0;
}</code></pre><p style="">5.2. std::shared_ptr 的自定义删除器</p><p style=""><code>std::shared_ptr</code> 的自定义删除器使用更加简单，因为删除器的类型不是模板参数的一部分。</p><p style="">使用示例</p><pre><code>#include &lt;iostream&gt;
#include &lt;memory&gt;
#include &lt;cstdio&gt;

int main() {
    // 使用 Lambda 作为 shared_ptr 的删除器
    auto file_deleter = [](FILE* file) {
        if (file) {
            std::cout &lt;&lt; "Closing file via shared_ptr deleter\n";
            fclose(file);
        }
    };
    
    std::shared_ptr&lt;FILE&gt; file(fopen("test.txt", "w"), file_deleter);
    
    if (file) {
        fputs("Hello, World!", file.get());
    }
    
    return 0;
}</code></pre><p style=""></p>
